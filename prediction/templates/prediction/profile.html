Endpoints

Method and URLPurpose
GET /api/health/ Status and model name (no token needed)
POST /api/predict/ Send the 13 values as JSON, receive probability, risk level, top factors and the trust check. Add "save": true to store it in your history.
POST /api/whatif/ Send the 13 values plus "changes": {"trestbps": 120, "chol": 200} and receive the estimate before and after.
GET /api/history/?limit=20 Your latest predictions

Example

Python example using an environment variable to keep your API token out of source code.

import json
import os
import urllib.request

url = "{{ request.scheme }}://{{ request.get_host }}/api/predict/"

token = os.environ["CARDIONOVA_API_TOKEN"]

data = {
    "age": 60,
    "sex": 1,
    "cp": 4,
    "trestbps": 150,
    "chol": 280,
    "fbs": 1,
    "restecg": 1,
    "thalach": 115,
    "exang": 1,
    "oldpeak": 3.0,
    "slope": 2,
    "ca": 2,
    "thal": 7
}

api_request = urllib.request.Request(
    url,
    data=json.dumps(data).encode("utf-8"),
    headers={
        "Authorization": "Token " + token,
        "Content-Type": "application/json"
    },
    method="POST"
)

with urllib.request.urlopen(api_request) as response:
    print(response.read().decode("utf-8"))
